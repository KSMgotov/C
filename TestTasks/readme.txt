Проект имеет следующую структуру: в директории TestTasks располагаются файлы Lexer.h и Lexer.cpp,
содержащие описание класса Lexer, отвечающего за лексический анализ, Parser.h и Parser.cpp,
содержащие описание класса парсер, отвечающего за синтаксичекский анализ, файл ParserTest.cpp, реализующий
программу для тестирования, файл CMakeLists.txt и поддиректория Stack, содержащая файл Stack.h, в котором описан шаблонный клас Stack,
файл my_exception.h, описывающий пользоватеьский класс исключений, а также CMakeLists.txt.
Для сборки проекта необходим Cmake версии не ниже 3.23. Сборка осущетсвляется последовательностью команд:
cmake <путь до каталога TestTasks>
make
Название исполняемого файла: ParserTest
Файлы Stack.h и my_exception.h собираются в одну библиотеку stack и подключаются к основному проекту.
